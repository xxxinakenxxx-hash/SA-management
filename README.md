# 鹿児島SA依頼管理システム

鹿児島の営業担当者からSA（営業支援担当）への依頼を受け付け、担当・進捗・やり取り・成果物を管理するシステムです。

- リポジトリ：`xxxinakenxxx-hash/SA-management`
- 開発担当：Claude Code
- 指示・管理：ChatGPT（`tasks/CHAT_CURRENT.md` を管理）

## 既存営業AIメモとの関係

- 全社共通の営業AIメモは原則変更しません。
- 本システムは鹿児島ローカル仕様として独立して管理します。
- 既存のユーザーマスターを活用する方針です。
- 既存GASとの連携方式は未確定です。

## 技術構成（採用方針）

以下は採用方針であり、正式な設計は未確定です。承認済みの業務仕様は `docs/正本/` に置く予定ですが、現時点では未作成です。

| 要素 | 用途 |
| --- | --- |
| GAS | 業務処理、既存営業AIメモとの連携 |
| Googleスプレッドシート | SA依頼・担当・進捗・スレッドの管理 |
| Google Drive | PDFなどの成果物の保管 |
| HTML・CSS・JavaScript | 画面 |
| PWA | Windows向けSA専用画面 |
| 営業用Web画面 | スマートフォン対応 |

業務方針：SA担当者は複数名、営業とのやり取りはスレッド方式、完了時には営業へ結果を返却します。
